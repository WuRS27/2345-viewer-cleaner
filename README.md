# 2345 看图王附加组件清理工具

一个 Windows 10 / Windows 11 便携工具，用于保留看图王，同时停用已确认的附加后台、守护及自动升级组件，并调用原软件的独立安全组件卸载器。

这是个人制作的第三方工具，与 2345 官方没有关联。

## 下载和使用

下载 [Windows 便携包 v1.0.0](downloads/2345-viewer-cleaner-v1.0.0.zip?raw=true)，解压后运行 `ViewerExtrasCleaner.exe`。包文件的 SHA-256 见 [SHA256SUMS.txt](downloads/SHA256SUMS.txt)。

1. 保存图片，关闭看图王、图片编辑和 PDF 等相关窗口。
2. 运行工具，允许 Windows 管理员权限请求，核对识别出的安装目录。
3. 点击“开始清理”。如果出现 2345 官方安全组件卸载窗口，点击“开始卸载”，完成后点击“确定”。
4. 按提示保存工作并重启 Windows，再打开图片确认功能正常。

未找到软件时，可手动选择含 `2345PicViewer.exe` 或 `2345Pic.exe` 的文件夹。程序还会检查当前 Windows 用户的看图王应用版本目录。

完整操作说明见 [使用说明.txt](使用说明.txt)。

## 处理范围

| 组件 | 处理方式 |
| --- | --- |
| 看图、编辑、截图、打印及 PDF 主程序 | 保留，并核对文件哈希 |
| `2345Pic` 后台服务 | 确认归属后停止并禁用 |
| `Protect` 守护目录和其中的附带安装器 | 备份并改名停用 |
| `2345PicWorker.exe` | 备份并改名停用 |
| `2345PicUpdate.exe` | 默认停用，可在清理前取消勾选 |
| 独立 2345 安全组件 | 验证原有卸载器后启动官方卸载流程 |
| 图片默认打开方式 | 读取并检查是否发生变化 |

工具自身不联网、不下载软件、不修改 Windows Defender，也不会自动重启。官方卸载器是电脑上已有的 2345 程序，其自身行为由原软件决定。

运行中的内核驱动不会被强制卸载。即使官方卸载器已将驱动禁用并标记删除，它们仍可能驻留内存，需要重启才能退出。

## 备份和恢复

备份存放在当前用户的 `%LOCALAPPDATA%\2345ViewerCleaner\Backups`。点击“查看备份”可直接打开。

“恢复停用项”支持分别恢复后台 Worker、升级程序或全部停用文件。只有主动勾选时才恢复后台服务；恢复服务可能重新带回推广和附加组件。

- 恢复前校验路径和文件哈希。
- 原路径已有文件时拒绝覆盖。
- 拒绝通过目录链接或重解析点处理其他位置。
- 记录每一步文件操作，支持改名后中断的恢复。
- 只接受同一电脑和 Windows 用户的备份。

恢复功能不会重新安装已经由官方卸载器移除的安全组件。

## 适用范围和限制

- 适用于已确认的 `2345Pic / Protect / Worker / Update / SafeCenter` 组件布局。遇到无法确认身份的文件或卸载器会跳过并提示。
- 不按“2345”字样批量删除文件，也不批量修改未知启动项、计划任务或其他软件。
- 安全组件可能被其他 2345 软件共用，可取消独立安全组件卸载选项。
- 工具不保证清除看图王所有页面中的推荐或会员入口。
- 默认停用自动升级。以后升级或重装看图王，应重新检查附加组件。
- 当前用户以外的用户目录可能不会被识别，请优先在安装软件的同一 Windows 用户下运行。
- 自制程序没有商业代码签名，Windows 权限弹窗可能显示“未知发布者”。发行包提供源码及 SHA-256 校验值。

## 从源码构建

使用 Windows 自带的 .NET Framework C# 编译器，无需下载依赖。

```powershell
.\build.ps1
.\test.ps1
.\package.ps1
```

可执行文件生成在 `release\ViewerExtrasCleaner.exe`，便携包生成在项目根目录。

只读扫描也可从命令行运行：

```powershell
.\release\ViewerExtrasCleaner.exe --scan "$env:TEMP\2345-viewer-scan.json"
```

该命令会写入指定的报告文件，不执行清理。
