看图王附加组件清理工具 v1.0
Windows 10 / Windows 11 便携版

如何在笔记本上使用

1. 将整个 ZIP 压缩包复制到笔记本，先解压到普通文件夹。
2. 保存正在编辑的图片，关闭看图王、图片处理、PDF 等相关窗口。
3. 双击 ViewerExtrasCleaner.exe，允许 Windows 的管理员权限请求。
4. 程序自动扫描。确认识别的是你的看图王后，点击“开始清理”。
5. 如果出现 2345 官方安全组件卸载窗口，点击“开始卸载”，结束后点击“确定”。工具最多等待 5 分钟；若你取消或尚未完成，结果会明确显示未完成。
6. 根据提示保存工作并重启 Windows。重启后再运行本工具扫描一次，并打开一张图片确认看图正常。

未找到安装目录时

点击“选择安装目录”，选择包含 2345PicViewer.exe 或 2345Pic.exe 的文件夹。
工具同时检查当前 Windows 用户的 AppData\Roaming\2345Pic\Application 版本目录。
请尽量在安装看图王的同一 Windows 用户下运行。如果管理员权限弹窗要求改用另一个账户，原账户的用户目录组件可能不会被自动识别。

会处理什么

• 保留看图主程序、编辑、截图、打印、PDF 等功能文件。
• 停止并禁用可确认归属的 2345Pic 后台服务。
• 备份并改名停用 Protect 守护目录，包含其中的安全中心安装器。
• 备份并改名停用已识别的 2345PicWorker.exe。
• 默认同时停用 2345PicUpdate.exe，防止自动升级带回附加组件。可在清理前取消勾选。
• 默认调用已验证路径、发布者与离线数字签名的独立“2345 安全组件”卸载器。此组件可能被其他 2345 软件共用；可以取消上方卸载选项。
• 核对主程序文件哈希、图片默认打开方式，并检查驱动是否需要重启退出。

处理范围

本版针对已确认的 2345Pic / Protect / Worker / Update / SafeCenter 组件布局。不同版本若使用其他组件名、不同目录或无法验证的卸载器，会跳过并提示。
它不是全系统卸载软件，不会按“2345”字样批量删除文件，也不直接批量清理未知计划任务、注册表启动项或其他软件。
本工具不直接修改 Windows Defender、防火墙、网络代理、用户图片或系统文件关联；官方卸载后会核对图片默认打开方式是否变化。
已加载的驱动由官方卸载器处理；标记删除后可能仍驻留内存，重启才能退出。本工具不会强行卸载运行中的驱动，也不会自动重启电脑。
停用自动升级后，后续升级需要手动恢复升级程序。升级或重装看图王之后应重新检查附加组件。
这里处理的是已识别的附加后台，不保证清除软件所有页面中的会员或推荐内容。

备份在哪里

点击“查看备份”即可打开。默认位置是当前用户的：
%LOCALAPPDATA%\2345ViewerCleaner\Backups

每次清理都有独立文件夹，保存扫描结果、相关服务注册表导出、文件副本、文件哈希和操作记录。
原目录中的附加文件也会保留为 .disabled-2345cleaner-时间编号 后缀，工具不永久删除这些停用副本。
不要在需要恢复时删除备份文件夹或停用副本。

如何恢复

1. 关闭看图王及相关窗口。
2. 点击“恢复停用项”，选择本机对应的一次备份。
3. 可选“仅恢复后台 Worker”“仅恢复升级程序”或“恢复全部停用文件”。
4. 只有选择全部文件时，才能额外勾选恢复后台服务。恢复后台服务可能重新带回推广和附加安装。

恢复只撤销本工具的文件改名及所选服务停用，不会重新安装已经通过官方卸载器卸载的安全组件。
如果原路径已有新文件、停用副本发生变化、路径是链接，或者备份来自其他电脑/用户，程序会拒绝覆盖并提示原因。
请使用本机备份恢复本机软件；不要把一台电脑的备份导入另一台电脑。

运行环境和联网

工具使用 Windows 10/11 自带的 .NET Framework，不需要安装 Python、Node.js 或开发工具。
工具自身没有联网、下载、自动更新或遥测功能。官方卸载器是电脑上已有的 2345 程序，其自身行为由原软件决定。
本工具为自制程序，未购买代码签名证书，因此 Windows 权限弹窗可能显示“未知发布者”。压缩包包含源码和 SHA-256 校验值供核对。

包内文件

ViewerExtrasCleaner.exe：运行程序。
使用说明.txt：本文。
SHA256.txt：主程序校验值。
Source：完整源码、构建脚本和独立测试源码。日常使用不需要打开该目录。

如果需要自行构建，可以在 Windows PowerShell 中进入 Source 文件夹后运行 build.ps1；它只调用 Windows 自带的 .NET Framework C# 编译器，不下载依赖。
